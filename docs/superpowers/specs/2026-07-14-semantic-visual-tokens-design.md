# Podcast Artist 语义视觉 Token 修正设计

**日期：** 2026-07-14
**状态：** 已确认，待实施计划
**范围：** 只修正视觉语义，不改布局、组件结构或业务行为

## 背景

现有深色界面把绿色同时用于品牌标记、导航、按钮、输入焦点、标题提示、时间线片段和播放状态。绿色因此从“运行信号”变成了整套界面皮肤，削弱了状态辨识，也偏离 `docs/podcast-artist-dark-ui-style-exploration.md` 与 premium mockup 所定义的“深夜编辑室”方向。

本轮把界面收回到冷中性石墨底、铂白主强调、绿色动态信号、银紫资料引用的语义体系。premium mockup 只用于校准色彩、层级和气质，不要求复刻其布局。

## 目标

- 去掉基础背景、面板、边框和静态控件中的绿色倾向。
- 让绿色重新只承担运行、播放、进度、选中波形和拖放可放置等动态信号。
- 建立中文优先字体栈，去掉中文小标题上的强制大写和宽字距。
- 让时间线 clip 回到中性表面，并把波形变成主要视觉信息。
- 删除播放头光晕，同时保留清晰的当前位置反馈。
- 保持现有键盘焦点、禁用状态、危险状态和减弱动画能力。

## 非目标

- 不改变页面布局、侧边栏宽度、面板层级、轨道高度或信息密度。
- 不改 JSX 结构、组件边界、事件处理、快捷键和持久化逻辑。
- 不引入主题切换、多主题架构、外部字体包或新的图标资产。
- 不把 premium mockup 当成像素级实现稿。

## 颜色系统

### 基础 token

实现时以以下目标值为准；半透明边界和交互态继续通过 `color-mix()` 从语义 token 派生，不再直接写带绿色倾向的局部颜色。

| Token | 目标值 | 职责 |
| --- | --- | --- |
| `--bg` | `#0b0e14` | 应用最深背景 |
| `--surface` | `#12161f` | 默认面板 |
| `--surface-2` | `#171c27` | 次级控件和嵌套区域 |
| `--surface-3` | `#1c222e` | 强调层或悬停层 |
| `--surface-elevated` | `#232a37` | 浮层和最高表面 |
| `--ink` | `#0e1118` | 深色前景和反色文字 |
| `--line` | `rgb(73 82 100 / 0.52)` | 低对比结构线 |
| `--line-strong` | `rgb(100 112 133 / 0.6)` | 标尺、工具栏等强结构线 |
| `--text` | `#e6eaf2` | 主文字 |
| `--muted` | `#a6adbb` | 次级文字 |
| `--muted-2` | `#70798a` | 辅助信息 |
| `--border` | `#252b36` | 默认边界 |
| `--border-strong` | `#384151` | 强边界 |
| `--accent` | `#d8dee9` | 铂白静态强调和焦点 |
| `--signal` | `oklch(0.78 0.085 142)` | 运行、播放、进度和时间线动态状态 |
| `--reference` | `oklch(0.76 0.026 300)` | 资料、引用和候选结果 |
| `--warn` / `--danger` / `--ok` | 保留语义色，但降低使用面积 | 警告、失败和明确成功反馈 |

`--signal-soft` 与 `--signal-fill` 可以保留，但只能用于短暂动态反馈，不得重新成为普通面板或静态控件底色。`--ok` 只用于明确完成或成功状态，不参与品牌、导航和普通选中态。

### 静态状态

- 品牌标记使用 `--accent` 派生的边框、文字和低对比底色。
- 导航选中、导航悬停和返回按钮悬停使用中性表面、铂白文字和中性边框。
- `.eyebrow` 与 `.panel-kicker` 使用 `--muted`，不使用信号绿。
- 输入框、按钮和可交互卡片的键盘焦点使用铂白描边。
- 主按钮使用铂白强调面和 `--ink` 深色文字；次按钮使用中性深色表面。
- 播放、缩放和裁切按钮的静止、悬停状态保持中性。只有组件真的进入运行或播放状态时才使用 `--signal`。

### 动态与语义状态

- `running`、播放头、进度、range 当前值、拖放可放置反馈和选中波形使用 `--signal`。
- 完成、成功、警告和失败继续使用各自语义色，但只作用于状态文字、细边界或小型提示，不铺满容器。
- 删除与危险操作继续使用 `--danger`。
- 资料任务、候选结果和引用相关动作继续使用 `--reference`。

## 中文排版

全局无衬线字体栈调整为：

```css
"OPPO Sans", "Source Han Sans SC", "Noto Sans CJK SC", "PingFang SC",
"Hiragino Sans GB", "Microsoft YaHei", ui-sans-serif, system-ui,
-apple-system, BlinkMacSystemFont, "Segoe UI", sans-serif
```

字体全部通过本机已有字体回退，不下载或打包字体文件。

- `.eyebrow`、`.panel-kicker` 和中文 `dt` 去掉 `text-transform: uppercase`。
- 上述中文标签的字距设为 `0`。
- 英文品牌名保留原始大小写，不改文案内容。
- 时间码、时间尺和纯数字信息继续使用现有等宽字体。
- 文稿阅读区保留当前 `1rem` 字号和 `1.92` 行高，只统一中文字体回退顺序。
- 不整体调整字号、字重或布局间距；现有标题与正文层级保持不变。

## 组件修正

### 通用控件

- 品牌、导航、返回按钮、主次按钮、输入焦点和普通 hover 从信号绿改为 `--accent` 或中性表面。
- modal 与普通表单中的按钮遵循同一套主次按钮语义，不保留局部绿色版本。
- 静态预览提示使用 `--reference`；只有正在执行的预览流程才允许使用信号绿。
- 危险、成功和资料引用状态保持各自语义，不被铂白统一覆盖。

### 时间线 clip

- 普通 clip 使用 `--surface-2` 底色和中性边框，悬停或选中时才提升到 `--surface-3`。
- 未选中波形使用银灰色，不使用绿色。
- 选中 clip 只通过细绿色边界和绿色波形表达状态，不使用大面积绿色填充或绿色阴影。
- 文件名标签使用半透明中性底色，降低存在感。
- 在不改变 76px clip 高度和 124px 轨道高度的前提下，缩小标签对波形区域的侵占，让波形占据 clip 的主要可视面积。
- focus-visible 使用铂白描边；选中态和焦点态可以同时辨认。

### 播放头与时间线反馈

- 播放头保留 1px 绿色竖线和紧凑顶部标记。
- 删除竖线与顶部标记的 `box-shadow`，不保留任何光晕。
- 时间线拖放可放置、播放位置和动态选中反馈继续使用 `--signal`。
- 标尺、网格、轨道标签和静止工具栏全部使用中性表面与边界。

## 行为、数据和错误处理

本轮没有新的数据流或错误分支。现有按钮事件、时间线交互、快捷键、任务状态和工作区持久化均保持原样。样式调整不得改变：

- `S` 切割和切割后直接删除的焦点行为；
- clip 选中、删除、拖放和轨道控制；
- 资料任务运行、完成和失败状态；
- modal、表单及 toast 的显示与关闭逻辑。

## 验收标准

在浏览器 mock 模式下，以相同视口逐页检查项目列表、设置、文稿/资料任务和音频时间线。

1. 基础背景、面板、边框和普通控件不再带绿色倾向。
2. 静态页面没有大面积绿色；信号绿只出现在运行、播放、进度、选中波形和拖放反馈。
3. 普通 clip 为中性表面，未选中波形为银灰色，选中波形为绿色。
4. 播放头清晰但没有光晕。
5. 中文小标题和字段名没有强制大写或明显宽字距。
6. 主按钮、次按钮、导航、输入和 clip 的默认、悬停、焦点、禁用与选中状态均可分辨。
7. 成功、警告、危险和资料引用状态仍能靠各自语义色辨识。
8. 页面布局、组件位置、轨道高度和交互行为与修改前一致。
9. `prefers-reduced-motion` 规则继续生效。

## 验证方式

- 运行完整自动化测试，确认样式改动没有破坏既有交互契约。
- 运行生产构建，确认 CSS 语法和打包结果正常。
- 在浏览器 mock 模式逐页进行视觉验收，并保存修改前后同尺寸截图。
- 对 `styles.css` 做静态搜索，确认绿色倾向的基础硬编码和静态 `--signal` 使用已经清理。
- 不新增依赖具体源码字符串的 CSS 单元测试；视觉语义通过静态检查、现有回归测试和浏览器验收共同验证。

## 预计改动边界

实现应主要集中在 `src/renderer/src/styles.css`。除非实施中发现无 CSS 选择器可以区分“静止”和“真正运行”状态，否则不改 `App.tsx`；如果确需增加状态 class，必须保持现有事件和数据流不变，并在实施计划中明确列出。
